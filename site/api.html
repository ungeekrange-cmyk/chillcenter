Pour les intégrations tierces

Une API, des clients compatibles.

Le contrat OpenAPI est la référence des routes, schémas, paramètres, réponses et erreurs. Cette page présente les principes d’intégration, pas un serveur de démonstration public.

Lire le contrat OpenAPI (JSON)

Adresse et version

L’API HTTPS du serveur configuré par l’utilisateur est sous /api/2026-10-14. Le port est configurable ; le contrat utilise https://{host}:8443/api/2026-10-14. Remplacer l’hôte par celui du serveur local. Utiliser le chemin versionné plutôt qu’un éventuel alias historique.

Requêtes et réponses

Les opérations JSON et leurs corps exacts sont décrits dans le contrat. Vidéos, images et échanges conditionnels n’ont pas tous une réponse JSON : respecter le type de contenu et les statuts de chaque route. Ne pas déduire la présence d’une fonction d’un seul numéro de version.

Catalogue et lecture

Les routes couvrent les profils, le catalogue, la synchronisation, les listes, les métadonnées et la lecture. Préférer les mécanismes de révision et de delta documentés à un rechargement complet du catalogue. Le serveur fournit les médias sans transcodage ; le décodage reste à la charge du client.

Évolution sans rupture

Des champs et opérations compatibles peuvent être ajoutés à cette version. Un client doit tolérer des champs de réponse inconnus. Une modification incompatible demande une nouvelle version et le maintien de celle utilisée par les clients existants, notamment le web. Tester sur le contrat et le serveur effectivement installés.

Réseau de confiance seulement

Aucune authentification actuellement. Les profils ne protègent pas les données contre un autre utilisateur du réseau. Ne pas exposer l’API sur Internet.

Le serveur utilise un certificat auto-généré. Une intégration doit prévoir sa politique de confiance après vérification du serveur ; désactiver globalement la validation TLS n’est pas une solution de production.

Services externes

TMDB et l’IA sont optionnels. Ne jamais incorporer de clé du foyer dans une application publique, un exemple, un journal ou un ticket. Ce site n’appelle ni votre serveur ni votre vidéothèque.
