# Web 0.7.12 — Icône d’onglet

## Français

L’icône Chill Center apparaît dans l’onglet. Le client déclare son PNG
dans le HTML et ajoute l’identifiant du build à son URL, en cohérence
avec le cache du service worker. Rechargez la page après mise à jour.

[web-v0.7.12](https://github.com/ungeekrange-cmyk/chillcenter/releases/tag/web-v0.7.12),
séquence 13, source `066d760b5abdc6a8ac4e09b642f1fc0897119692`, build `78633fd17533`.
Publié et installé sur le Pi le 21 novembre 2026. Chrome a chargé et
décodé l’icône du build. Les six assets publics ont été comparés aux
paquets signés. Le Pi a servi 90 ressources
identiques au ZIP, y compris l’icône demandée à son URL HTTPS versionnée.
La progression vérifiée est inchangée.

## English

The Chill Center icon appears in the browser tab. The HTML declares the
existing PNG with the build identifier in its URL, matching the service
worker cache. Reload the page after updating.

Web 0.7.12 was published and installed on the Pi on 21 November 2026.
Chrome loaded and decoded the icon in the build. All six public assets
matched the signed packages, and the Pi served the expected icon at
its versioned HTTPS URL.
