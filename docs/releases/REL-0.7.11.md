# 0.7.11 — Navigation et pictogrammes / Navigation and icons

## Français

Dans le client web mobile, **Accueil**, **Films** et **Séries** restent accessibles dans la barre du bas. **Téléchargements** apparaît quand le profil a une copie locale, et **…** ouvre les autres rubriques. Les pictogrammes au trait fin utilisent la palette active en clair et en sombre, sur le web et sur Mac.

Cette livraison contient **macOS 0.7.11** (build 21) et le **client web 0.7.15**. Le serveur compatible est la [version 0.7.11 déjà publiée](https://github.com/ungeekrange-cmyk/chillcenter/releases/tag/server-v0.7.11). Les thèmes sont en version **0.7.1**.

## English

On phones, the web client keeps **Home**, **Movies** and **TV shows** along the bottom. **Downloads** appears for profiles with local copies, and **…** opens the other sections. The line icons follow the active light or dark palette on the web and Mac.

This release includes **macOS 0.7.11** (build 21) and **web 0.7.15**. The compatible server is the [existing 0.7.11 release](https://github.com/ungeekrange-cmyk/chillcenter/releases/tag/server-v0.7.11). Themes are on **0.7.1**.
