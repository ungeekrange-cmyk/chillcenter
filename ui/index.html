Métadonnées

Créez un jeton dans votre compte themoviedb.org → Paramètres → API. Les fiches sont complétées sur correspondance exacte ; choisissez les résultats ambigus dans Détails.

Ce produit utilise l’API TMDB mais n’est ni approuvé ni certifié par TMDB.

Organisation IA

Connectez le CLI dans le Terminal avec « codex login » ou « claude auth login ». L’IA reçoit les titres et métadonnées du catalogue — jamais les vidéos. Elle utilise cette connexion et ses quotas. Les changements sont appliqués seulement après votre validation, dans le catalogue local.

La dictée française dure 12 secondes et demande les autorisations macOS. Elle utilise les services de reconnaissance Apple, sur l’appareil lorsque disponibles.

Supprimer du catalogue ?

Les fiches, notes et associations aux sagas/listes de ces vidéos seront supprimées de la base locale. Aucun fichier ne sera supprimé du NAS. Si les vidéos réapparaissent lors d’un prochain scan, elles seront indexées à nouveau sans ces informations.

Supprimer ?

Seule cette collection et ses associations seront retirées. Les vidéos, les autres collections et les fichiers du NAS seront conservés.
